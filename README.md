# Rakshith Dongari | Portfolio Website

A personal portfolio website designed to showcase my academic background, technical skills, projects, achievements, and contact information in a modern and responsive layout.

## Design Rationale

The portfolio follows a minimal, elegant design approach using a warm hazel-brown color palette to create a professional yet approachable appearance. The combination of soft beige backgrounds, muted brown accents, and subtle shadows provides a clean visual hierarchy while keeping the interface comfortable for long viewing sessions.

The website is structured into different sections including About Me, Education, Projects, Technical Skills, Achievements, and Contact. Each section is designed as an independent visual block to improve readability and navigation.

## Layout Technique Justification

The layout is implemented using modern CSS techniques including **CSS Grid** and **Flexbox**.

- CSS Grid is used for major page structures such as the split-section layout, project areas, achievement cards, and contact section to create balanced column arrangements.
- Flexbox is used for navigation alignment, buttons, skill tags, and smaller component layouts.
- Responsive media queries ensure that the website adapts smoothly across different screen sizes including tablets and mobile devices.

The design follows a component-based approach where cards, buttons, and content sections maintain consistent spacing, border-radius, colors, and shadows throughout the website.

## Technologies Used

- HTML5
- CSS3
- Google Fonts (Poppins)
- CSS Grid
- Flexbox
- Responsive Web Design

## Features

- Responsive portfolio layout
- Interactive navigation
- Project showcase section
- Skills and achievements display
- Contact form interface
- Modern hazel-beige visual theme

## Known Limitations

- The contact form is currently a frontend-only interface and does not submit data to a backend service.
- Project buttons and social media links are placeholders and need to be connected with actual URLs.
- Animations and advanced interactions are limited to maintain performance and simplicity.

## Future Improvements

Future enhancements include adding backend integration for the contact form, improving accessibility, adding project filtering, and introducing more interactive animations.
